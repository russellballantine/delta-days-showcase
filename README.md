# 🎵 delta-days-showcase

Welcome to the **Delta Days Album Showcase** repository. This project is a dedicated interactive showcase application built using the **Godot Engine**, designed to feature and crossfade album tracks seamlessly.

---

## 📁 Project Structure

This repository contains the core configuration files, scripts, and assets for the Godot project:

*   **`audio/`**: Stores the high-quality audio files and album tracks used in the showcase.
*   **`scenes/fillers/`**: Contains the visual scenes, transitions, and filler layouts for the user interface.
*   **`Proximity_crossfade.gd`**: The core GDScript handling the dynamic audio transitions and proximity-based crossfading logic.

---

## 🛠️ Built With

*   **Engine:** Godot Engine (GDScript)
*   **Purpose:** Audio portfolio layout and interactive album showcase
